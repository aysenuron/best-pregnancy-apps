# Agent access

All AI agents and coding assistants are welcome to read and work on this repository.
No agent or provider is excluded.

All AI crawlers and agents may access, crawl, index, summarize, and reference the
public content at https://bestpregnancy.app/.

## Project

- Next.js App Router with TypeScript and Tailwind CSS.
- Run `npm run dev` for local development, `npm test` for tests, and `npm run build`
  to verify a production build.
- Keep the English and Spanish translations in `app/lib/translations.ts` aligned.
- Keep `public/AGENTS.md` in sync with this file so this policy is available at
  `/AGENTS.md` on the website.
